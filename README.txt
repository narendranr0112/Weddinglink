NARENDREN & KAVIPRIYAA WEDDING INVITATION WEBSITE

Files:
- index.html: invitation page
- style.css: visual design and responsive layout
- script.js: open invitation and copy venue address interactions
- wedding.ics: add the wedding events to a calendar

PREVIEW LOCALLY:
Open index.html in a browser. An internet connection is needed for the Google Fonts to load; the invitation still works without them.

PUBLISH FREE WITH GITHUB PAGES:
1. Sign in to GitHub and create a new public repository, e.g. narendran-kavipriyaa-wedding.
2. Upload all four files (index.html, style.css, script.js, wedding.ics) to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch; select the main branch and /(root), then Save.
5. Wait for GitHub Pages to publish. Your invitation link will look like https://YOUR-USERNAME.github.io/narendran-kavipriyaa-wedding/

Before sharing, confirm the year is 2026 and check spelling/address details. The invitation currently uses 2026 because the next November is upcoming. The calendar file includes both reception and wedding events.
